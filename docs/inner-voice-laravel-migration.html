Inner Voice / Laravel Migration

Change the engine. Preserve the product.

Rewrite the Next.js application as a lean Laravel application without changing user data, product behavior, Chrome capture, AI contracts, or deployment ownership.

Migration Promise

This is a controlled rewrite, not a feature project. Every Laravel slice must reproduce one verified behavior from the current application. The existing Next.js app remains the reference until Laravel passes all parity and recovery gates.

Stable Decisions

Framework
Laravel with server-rendered Blade. No React or Next.js.
Frontend
Existing visual design, normal CSS, and only required vanilla JavaScript.
Database
Existing SQLite schema and IDs remain compatible.
Data access
Laravel Query Builder first. No ORM requirement during parity work.
Authentication
Single shared password with Laravel session and custom middleware.
AI
Laravel HTTP client calls the same OpenAI Responses API and strict JSON Schema.
Extension
Manifest V3 source and POST /api/capture contract stay unchanged.
PHP tests
PHPUnit unit and feature tests.
Extension tests
Node built-in test runner; Node remains development-only.
Assets
No Vite pipeline. CSS, JS, fonts, and SVG icons served as static assets.
Production
Hetzner VPS, Cloudflare Tunnel, Tailscale, PHP-FPM, and a small web server.
Excluded
No Livewire, Tailwind, PostgreSQL, Redis, Pest, Playwright, Sanctum, queue, or Docker.

Migration Stages

  1. Done

    1. Freeze The Compatibility Baseline

    Define observable behavior before creating Laravel code.

    • done: record routes, request/response shapes, cookies, env names, and compatibility requirements in docs/LARAVEL_MIGRATION_CONTRACT.md
    • done: current 49 tests pass; representative search and AI recall cases are recorded
    • done: current source and CSS are the UI reference; Chrome comparison waits until Blade exists
    • done: a verified SQLite backup was restored and compared in isolation
    • done: migration-only DB copies exist outside Git; the original file was not modified
  2. Done

    2. Build The Laravel Foundation

    Create the smallest Laravel runtime beside the current app.

    • done: Laravel 13 runs in laravel/ without Vite, Tailwind, queues, or default user/cache/jobs tables
    • done: Laravel read 4 ideas from the copied SQLite baseline; integrity passed and its SHA-256 remained unchanged
    • done: fresh-install migration creates the exact notes schema and safely skips an existing notes table
    • done: PHPUnit, encrypted cookie sessions, JSON stderr logging, static assets, and env example are configured
    • done: local setup/run/test commands are documented; Next.js remains the behavior reference
  3. Done

    3. Rebuild Core Product In Vertical Slices

    One behavior per reviewed slice. No big-bang frontend rewrite.

    • done: single-user login, route protection, and logout
    • done: idea collection read view and direct note view
    • done: create, edit, cancel, save, and delete
    • done: Blade collection/composer UI parity, existing CSS adaptation, and minimal DOM interaction modules
    • done: keyword search, SQL wildcard escaping, and local lexical recall ranking
    • done: fullscreen keyword/AI search UI and authenticated AI recall
    • evidence: 31 Laravel tests with 130 assertions, Chrome parity checks, and one approved live OpenAI call passed
  4. In progress

    4. Restore AI, Extension, And Operations Parity

    Reconnect paid and operational boundaries only after core behavior is stable.

    • done: accept the Stage 3 AI recall port after automated, Chrome, and approved live-call verification
    • done: restore /api/capture bearer auth without session or CSRF coupling; focused tests pass
    • connect the unchanged extension to Laravel, then convert its tests from Vitest to Node built-in tests without changing extension behavior
    • port structured logs and privacy rules
    • replace Node backup with verified Artisan backup and restore commands
  5. Pending

    5. Cut Over With A Rollback Gate

    Switch only after behavior, data, deployment, and recovery evidence pass.

    • run full PHP and extension test suites
    • compare old/new UI and golden search/AI cases
    • backup real SQLite, deploy Laravel beside current service, and run smoke tests
    • switch traffic while preserving old release and database backup
    • remove Next.js runtime only after an observation window and restore rehearsal
    • update architecture, security, deployment, operations, project memory, README, and canonical stage map

Safety Gates

  • No write against original DB before compatibility proof.
  • No stage closes with failing parity tests.
  • No paid AI call in broad automated tests.
  • No extension secret enters client logs or source.
  • No production cutover without tested backup restore.
  • No deletion of Next.js reference before rollback window ends.
  • No new product features during migration.
  • No framework extras without a proven requirement.

Data rule: Git rollback restores code, not SQLite data. Every destructive migration or cutover requires a separately verified database backup and restore path.

Definition Of Done

  • Laravel is the only production application runtime.
  • Existing SQLite data opens without lost or rewritten notes.
  • Auth, CRUD, keyword search, AI recall, and Chrome capture preserve approved behavior.
  • PHPUnit and extension tests pass; critical workflows pass manually.
  • Logs, backup, restore, deployment, and rollback instructions are verified.
  • No excluded framework or infrastructure dependency was introduced.
  • Current documentation describes Laravel, not the retired Next.js architecture.

Tradeoff

Benefit: simpler server-rendered runtime, Laravel conventions, fewer frontend build concerns. Cost: complete UI and backend rewrite, temporary dual-stack maintenance, fresh deployment knowledge, and regression risk. Parity gates buy safety by making migration slower.
